Coin Refill

Set the Game Corner coin counter to 9,999 in a Pokémon FireRed or LeafGreen save, so you can buy every prize despite the cap.

Your save never leaves your phone. Everything happens in this browser tab — there is no upload and no server.

Before you start

  1. In the game, save at the Game Corner.
  2. In RetroArch, open the menu and choose Close Content.
    Not pause — RetroArch keeps the save in memory and would overwrite your change if the game is still open.

On Android it is usually under RetroArch/saves/. If you can't find it, check RetroArch → Settings → Directory → Save Files.

⚠️ Do not rename the file. It must still be called the same name when you put it back. RetroArch finds your save by its name, so if the name changes even slightly the game will load as if nothing happened.

Watch out: if a file with that name is already in your Downloads folder, your browser may save this one as … (1).srm instead. If that happens, rename it back before moving it.

Works on FireRed, LeafGreen and FireRed-based rom hacks such as FRLG+.
Does not work on Ruby, Sapphire or Emerald.
